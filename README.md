TimePRO - Professional Activity Tracker
TimePRO is a sleek, dark-themed web application designed to help users log, track, and manage their daily work activities. It features a responsive dashboard, real-time activity logging, and a full suite of management tools to keep projects organized.

🚀 Features
> Real-time Time Logging: Quickly log tasks with specific start and end times.

> Dynamic Activity List: View recent logs instantly with automated duration calculations.

> Edit & Delete Capabilities: Full CRUD functionality to modify or remove entries.

> Project & Work Type Management: Categorize tasks by project and work type for better reporting.

> Responsive Dark Mode UI: A modern interface built with a mobile-first approach using CSS variables.

> Global Navigation: Seamless switching between the Logger, All Logs, and Management views.

🛠️ Tech Stack
> Frontend: React.js, React Router DOM

> Icons: Lucide-React

> Styling: Custom CSS3 (Modern Flexbox/Grid + Variables)

> Backend: Node.js, Express (Expected)

> Database: Local SQL/NoSQL (Localhost environment)
